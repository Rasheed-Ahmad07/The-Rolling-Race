🎲 The Rolling Race

The Rolling Race is a fun and interactive two-player dice game built using HTML, CSS, and JavaScript. Players take turns rolling a die to accumulate points — but beware! Rolling a 1 will reset your current score and pass the turn to your opponent. The first player to reach 100 points wins the race!

🚀 Live Demo

Download or clone the repository and open index.html in your browser to start playing!

👉 GitHub Repository : https://github.com/Rasheed-Ahmad07/The-Rolling-Race

🕹️ How to Play

Two players take turns.

Each turn, the player:

Clicks 🎲 Roll dice to roll.

If the number is not 1, it adds to the current score.

If the number is 1, the current score resets to 0 and the turn ends.

The player can choose to 📥 Hold at any time:

This adds the current score to the total score.

Then it switches to the other player.

The first player to reach 100 total points wins!

🛠️ Tech Stack

HTML5 – Markup structure

CSS3 – Visual styling and layout

JavaScript – Interactive game logic
